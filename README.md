# Music Streaming Queries

A C program that loads a music-streaming dataset (artists, songs, albums, users, and listening history) from CSV files into custom in-memory data structures, then answers a set of queries over that data. Built for the Computer Labs III course at the University of Minho.

## Features

- Custom hashtable-based storage for artists, songs, albums, users, and history
- CSV parsing with logical and syntactic validation
- Query engine answering statistics such as user/artist summaries, weekly top artists, and yearly listening summaries
- Three execution modes: main, interactive, and test
- All dynamically allocated memory is explicitly freed before the program exits

## Tech stack

C, Doxygen, Make.

## Run locally

```bash
make
./programa-principal dataset/ inputs.txt
```

`dataset/` is the path to the folder containing the CSV files (artists, songs, albums, users, history), and `inputs.txt` is the file listing the queries to run. Interactive and test modes are also available as separate executables generated by the Makefile.

> **Note:** the original dataset provided by the course is not included in this repository and is not currently available to run the program end-to-end.
